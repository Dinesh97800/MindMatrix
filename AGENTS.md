# Image Asset Rules

For all website images created or added by Codex:

- Final production images MUST use `.webp`.
- Never leave generated PNG/JPG files in production assets.
- Convert generated images to WebP automatically.
- Hero/background images:
  - WebP
  - quality: 82–88
  - optimized for web
  - maximum practical resolution around 1920–2560px wide
- Preserve transparency when required.
- Use descriptive filenames:
  `ev-charging-ecosystem-hero.webp`
  `remote-connectivity-network.webp`
- Store images in the appropriate `/public/images/...` directory.
- Update all code references automatically.
- Avoid text inside generated images unless explicitly requested.
- Images should look realistic, professional, humanized, and consistent
  with the existing website brand.
